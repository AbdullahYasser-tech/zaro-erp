# ZARO ERP

نظام عربي مبسّط لإدارة الأوردرات والمنتجات والمخزون والشحن والمصاريف وحساب **Max CPP**، مع قاعدة بيانات مشتركة وتحديثات لحظية عبر Supabase.

## الإعداد

### Supabase

أنشئ مشروع Supabase، ثم شغّل `supabase_setup.sql` مرة واحدة لإنشاء حالة النظام الأساسية، وبعدها شغّل `supabase_setup_auth.sql` لإضافة المصادقة والأدوار ودعوات الإيميلات. في بيئة الإنتاج تُدار التغييرات الجديدة عبر الملفات الموجودة داخل `supabase_migrations/`، ويجب تطبيق migration الدعوات `20260814080720_add_invited_users_feature.sql` قبل تشغيل نسخة الواجهة التي تعرض شاشة الدعوات.

ضع عنوان المشروع والمفتاح العام في `src/supabaseClient.js`، ولا تضع أي مفتاح خدمة أو مفتاح إداري داخل الواجهة الأمامية أو مستودع GitHub.

### الأدوار

يدعم النظام الأدوار التالية:

| الدور | الصلاحيات |
| --- | --- |
| المالك | إدارة كل الأقسام، إدارة المستخدمين، تغيير الأدوار، وإضافة دعوات مسبقة |
| المحاسب | تعديل الأوردرات والتحصيلات فقط |
| المشاهدة فقط | قراءة البيانات والتقارير دون تعديل |
| بانتظار الموافقة | لا يدخل إلى النظام حتى يوافق المالك ويحدد الدور |

### دعوة مستخدم قبل التسجيل

من تبويب **إدارة المستخدمين** يستطيع المالك إدخال الإيميل واختيار الصلاحية. تُحفظ الدعوة في `invited_users`، وعندما ينشئ الشخص حسابًا بالإيميل نفسه يحصل تلقائيًا على الدور المحدد ثم تُحذف الدعوة المستهلكة. لا يُنفّذ هذا المسار إلا عبر سياسات RLS التي تسمح للمالك فقط بإدارة الدعوات.

## النشر على GitHub وVercel

اربط المستودع بـ Vercel باستخدام إطار Vite، واجعل النشر الإنتاجي من الفرع `main`. قبل أي نشر، نفّذ `npm ci` ثم `npm run build`، وطبّق migrations قاعدة البيانات في بيئة التطوير أو الإنتاج حسب الحاجة. لا تنشر نسخة من المستودع إذا كانت بيئة الإنتاج تحتوي على تغييرات غير محفوظة فيه؛ افحص فرق الإصدارات أولاً.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## ملاحظات أمنية

التعديلات على بيانات النظام تمر عبر الدالة `zaro_update_section` التي تتحقق من الدور داخل قاعدة البيانات. تغيير صلاحيات المستخدمين يمر عبر `zaro_set_user_role`، وإدارة الدعوات محمية بسياسة RLS خاصة بالمالك. يجب تفعيل تأكيد البريد وحماية كلمات المرور المسرّبة من إعدادات Supabase Auth قبل الاستخدام التجاري.
